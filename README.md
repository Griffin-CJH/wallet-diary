# 钱包日记 wallet-diary

一句话记账的 AI Agent skill。你说「中午面 25 支付宝」，Agent 帮你记进本地账本；想回顾的时候说「回顾九月」，它会把这个月的账写成一章可以翻页的日记，讲你的钱包这个月发生了什么。它不做记账 App 那种 dashboard。

> 早期版本，还在边用边改。

## 能做什么

- **一句话记账**：「中午面 25 支付宝」「工资到了」「打车 32，昨天的」。一句话里有好几笔也能拆开记，你的原话会原样存下来。
- **改账、删账**：删掉的记录会留底，可以找回。
- **校准余额**：告诉它「支付宝现在 1234」，它会算出差额并补一笔校准。
- **定期收支**：订阅、房租、工资这类，到期会先问你再记。
- **问数**：「昨天花了啥」「这周吃饭多少」。
- **顾问**：「这个能买吗」「分 12 期扛得住吗」，拿你的真实余额和收支来回答。
- **生成一章日记**：「看看最近」「回顾九月」，生成一个 HTML 页面：开头一段话，几条它从账里发现的事，每条都能点开核对是哪几笔账，后面附整月的流水和趋势。

## 设计原则

- **数字全部由脚本算**：余额、合计这些都由 `wallet.py` 算出来，Agent 只负责理解你说的话、写日记的文字，不心算。
- **只陈述，不说教**：超支了也只说事实，不批评，不给建议。

## 安装

**Claude Code**：把本仓库放进 skills 目录，文件夹名用 `wallet-diary`。

```bash
git clone https://github.com/Griffin-CJH/wallet-diary ~/.claude/skills/wallet-diary
```

也可以在仓库页面点 **Code → Download ZIP**，解压后把文件夹改名为 `wallet-diary`，放进 `~/.claude/skills/`（只想在某个项目里用，就放进那个项目的 `.claude/skills/`）。

**其他支持 skill 的 Agent**：如果它支持用 GitHub 链接导入 skill，直接粘贴本仓库链接。前提是这个 Agent 能读写本地文件、能运行 Python。

装好后对 Agent 说一句「中午面 25」，它会先带你建账本：问你数据放在哪个文件夹、用什么币种、有哪些账户。

## 依赖

- Python 3，只用标准库，不用 `pip install`。

## 数据放在哪

- 账本是几个 CSV 文件，放在你第一次使用时自己指定的文件夹里。这个文件夹的位置记在 `~/.wallet-diary.json`。
- 脚本不联网，账本只在你本地。
- 生成的日记页面会从 Google Fonts 加载字体，加载不了时用系统字体，不影响内容。

## 文件

| 文件 | 作用 |
|---|---|
| `SKILL.md` | 给 Agent 看的记账规则 |
| `wallet.py` | 所有的计算和账本读写 |
| `review.md` | 生成一章日记时的写作规则 |
| `template.html` | 日记页面的模板 |
